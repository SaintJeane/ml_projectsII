# Overview
------------------------------------------------------------
Repository contains Computer Vision based and Natural Language Processing (RAG based) machine learning projects.

They are:
  - [`Object Detection (Computer Vision)`](https://github.com/SaintJeane/ml_projectsII/tree/main/rag_systems): 
      Contains `Drawing_Bounding_Box.ipynb` demonstrating how to effectively draw a bounding box on an image and `Object_Detection_Notebook.ipynb` showcasing the building of the actual object detection system and its deployment into Hugging Face Spaces for live inference.

  - [`Rag Systems (NLP)`](https://github.com/SaintJeane/ml_projectsII/tree/main/rag_systems): subfolder is divided into:
  
    - [`local_rag`](https://github.com/SaintJeane/ml_projectsII/tree/main/rag_systems/local_rag): consists of local rag system built from scratch.

    - [`multimodal_rag`](https://github.com/SaintJeane/ml_projectsII/tree/main/rag_systems/multimodal_rag): contains implementation of a local multimodal rag.
